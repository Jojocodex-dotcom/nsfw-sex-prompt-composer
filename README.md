# NSFW Sex Prompt Composer

可视化成人性爱提示词组合器（MINIMAX H3 / QWEN IMAGE 2.1）+ ComfyUI 插件。

**21+ only** — 自愿虚构成人内容。禁止未成年、年龄模糊、真实名人姓名/肖像。本仓库只提供提示词工具与文本模块，不托管色情媒体。

## 网页组合器

```bash
cd .  # 本仓库根目录
python3 -m http.server 8765
# 打开 http://127.0.0.1:8765/
```

功能：模型/模式切换、积木点选、多动作时间轴（一镜到底 / 多镜头）、复制与导出。

## ComfyUI 插件

见 `ComfyUI-NSFWPromptComposer/README.md`。复制到 `ComfyUI/custom_nodes/` 后重启。
