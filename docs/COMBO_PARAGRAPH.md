# 可自由组合示例话术（填空式）· 21+

> 所有角色均为自愿的 **21 岁及以上** 虚构成人。禁止未成年、年龄模糊、真实名人姓名/肖像。  
> 将【方括号】内容替换为你的积木；秒数可改为 3 / 5 / 8 / 10 / 15。

---

## 通用填空骨架

**【主体】** 一名成年【男/女】与一名成年【男/女】（双方明显 21+）  
**【场景】** 【卧室夜灯 / 酒店套房 / 浴室蒸汽 / …】  
**【服装】** 【情趣内衣未脱尽 / 全裸 / …】  
**【节奏】** 【逐渐升温 / 激烈猛烈 / …】  
**【镜头】** 【中景半身 + 缓缓推进 / 固定机位 / …】  

**时间轴（示例 3 段，可增减）：**

| 段 | 类别 | 动作（替换） | 秒数 |
|----|------|--------------|------|
| 1 | 前戏 | 【深吻纠缠】 | 【3s】 |
| 2 | 口交 | 【跪姿口交】 | 【5s】 |
| 3 | 性交 | 【传教士】 | 【8s】 |

## 版本 A · 一镜到底（continuous take）

把下列段落中的【】改成你的选择后整段粘贴：

```
所有角色均为明显自愿的21岁及以上成年人。仅虚构成人内容。

IMAGE-TO-VIDEO：保持首帧中的面部身份、成人体态、接触点、服装状态、光照方向与背景布局。不要重写外貌。只做从当前姿势可到达的动作。

主体：【一名成年男性与一名成年女性，双方明显21岁以上】
场景：【夜间暖色卧室，凌乱床单，床头灯柔光，私密氛围】
服装道具：【情趣内衣未脱尽：吊带滑落、内裤拨开】
叙事弧：【完整弧：温柔开始 → 激烈高潮 → 余韵拥抱】

动作时间轴（一镜到底，合计约 【15】 秒，3 段）：
【节拍1｜0–3秒｜0–19%】【深吻，舌尖由缓至急，双手插发】
【节拍2｜3–8秒｜19–50%】【跪姿口交，唇沿柱身滑动，上抬对视，唾液光泽】
【节拍3｜8–15秒｜50–100%】【传教士：仰躺双腿环腰，面对面深顶】
过渡衔接：
过渡 1→2：一镜到底 morph——保持身体接触；经可到达的中间姿势转入「跪姿口交」；禁止硬切；身份、接触点、服装、光照与运镜路径保持平滑。
过渡 2→3：一镜到底 morph——保持身体接触；经可到达的中间姿势转入「传教士」；禁止硬切；身份、接触点、服装、光照与运镜路径保持平滑。
一镜到底约束：单一连续镜头；节拍间柔和 morph；禁止跳切；禁止身份漂移；接触点解剖正确；运镜连续（优先一个主运镜）。

节奏：【由缓渐快升温，呼吸逐渐同步】
镜头：【中景大腿以上；镜头缓缓推向两人】。优先一个主运镜。平滑连续运动，禁止突然阶跃剪辑。
表情声音：【微张口轻喘；自愿成人深情对视】
声景：私密室内底噪；肌肤接触；与动作同步的喘息轻吟；床单摩擦。
```

**英文要点（可并入 EN 块）：**  
`ONE CONTINUOUS TAKE` · beat timeline with morph/transition · preserve identity & contact points · no hard cut.

【节拍1｜0–3秒】【深吻纠缠】——镜头：过肩 / 面部特写
【节拍2｜3–8秒】【跪姿口交】——镜头：中景半身，略低机位
【节拍3｜8–15秒】【传教士】——镜头：中景 + 缓缓推进
过渡衔接：

剪辑 2→3：match cut / raccord——从「跪姿口交」匹配视线与动作惯性切入「传教士」；出入画连贯；跨镜保持成人身份；避免服装/接触点跳切穿帮。
多镜头约束：每段一镜；使用 match cut / 视线匹配 / 动作匹配 / raccord；禁止破坏空间连续的跳切；跨镜锁定面部与体态身份；服装与接触点不得瞬移。

节奏：【由缓渐快升温】
